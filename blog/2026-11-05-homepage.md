本次更新完成首页内容精简、实机照片替换和相关部署信息调整。

{/* truncate */}

## 首页调整

- WS2024-Lyon Agri-AMR 产品卡、首屏主视觉和“开始使用”区块改用实机照片。
- 删除独立的“特性”区块，将学习路径与通用内容模块合并为“学习路径与内容模块”。
- 学习路径按产品认知、首次上手、开发准备、应用开发四个阶段组织，并直接关联对应文档。
- 通用内容模块显示实际文档分类、篇数和入口，便于从首页进入开发环境、基础教学、YOLO 和常见问题。
- 调整调试工具区、常见问题区和页面底部引导区的文案，补充工具分类、版本和下载资源说明。

## 文档与部署

- 仓库链接统一更新为 [hbrobot/hbrobot](https://github.com/hbrobot/hbrobot)。
- GitHub Pages 部署配置按项目站点路径 `/hbrobot/` 调整，站点访问地址为 `https://hbrobot.github.io/hbrobot/`。
- 静态资源路径统一使用 Docusaurus 的 base URL，确保项目站点下图片和资源正常加载。

## 问题修复

- 修复暗色模式下 WS2026 预留产品卡背景与文字对比度不足的问题。
- 调整移动端实机照片尺寸和底部间距，避免图片被产品卡边缘裁切。
- 修复代码块内容在圆角边缘被裁切的问题，恢复代码块内边距并调整复制按钮位置。
- 修复首页合并后部分模块区块在小屏幕下的排列和间距问题。

## 验证

- TypeScript 类型检查和生产构建通过。
- 使用 `/hbrobot/` 作为基础路径的构建通过，图片与社交分享资源路径正确。
- 首页、产品页、文档总览、工具页和更新日志等主要路由检查正常。
- 桌面端与 320px、390px 移动端无页面横向溢出。
